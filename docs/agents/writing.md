# Writing

- Use ASD-STE100 (Simplified Technical English) as the guide for technical
  writing: short, direct sentences, consistent technical terms, explicit
  actions, and one instruction per step. Preserve exact code identifiers
  and command names. Do not claim formal compliance without checking it.
- Use George Orwell's writing rules for prose: prefer short, familiar
  words; cut unnecessary words; use active voice; avoid stale metaphors,
  jargon, and inflated phrasing. Put clarity and accurate meaning ahead
  of mechanical adherence to a rule.
- Apply these styles to responses, documentation, code comments, commit
  messages, issue plans, PR descriptions, and release notes.
- For comment content, follow [Code comments](development.md#code-comments).
  For commit structure and context, follow
  [Commit messages](delivery.md#commit-messages).
